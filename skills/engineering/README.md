# Engineering Skills

Skills for shaping software structure, dependencies, and delivery behavior.

## Model-invoked

- [codebase-design](../../docs/codebase-design.md) - design cohesive modules, evidence-gated abstractions, intentional dependency direction, and explicit inter-module contracts.
- [code-review](../../docs/code-review.md) - review changes at quick, standard, or deep depth with a bounded default and evidence-backed findings.
