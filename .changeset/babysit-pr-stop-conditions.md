`babysit-pr` now has explicit stop conditions. Without a user deadline a run
is capped at 5 repair waves and 8 hours of active watch time, kept across
resumes. A fix that keeps coming back on later heads is parked as
non-convergence, five consecutive failed GitHub reads pause the run, and
product, design, architecture, security, auth, billing, data and migration
feedback is escalated by name. Replies are marked as automated; reviews, draft
and open state, and threads other people joined are left alone; hooks always
run and pushed commits are not amended. The final report leads with a status
line and states budget use and dismissed findings. The watcher skips
unsubmitted pending reviews, and behavior-changing repairs refresh the PR
description through `pr-description`. When several reviewers have commented,
`references/TRIAGE.md` sorts the feedback. It drops bot noise, merges duplicate
findings across bots, takes human comments first, gives each finding a Fix,
Dismiss or Escalate outcome, and keeps a ledger so no comment is handled
twice.
